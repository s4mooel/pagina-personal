# Project rules
- Keep palette roles in global CSS and consume semantic Tailwind tokens so visual changes stay consistent across sections.
- Use the existing Button component for opening-section actions so keyboard and focus behavior stays consistent.
- Serve the original CV as a same-origin static download so visitors receive the unmodified PDF without client-side generation.
- Use semantic vector icons for generic SQL and machine-learning concepts and unavailable tool marks so these tiles never rely on initials.
